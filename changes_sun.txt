The cbfOverDwa takes a barrier function by calling BFCreation (thanks to Alex) which calls PRoTECT to find that BF given specific dynamics, obstacles, states, etc. Then applies it as CBF filter over the DWA approach. Although, this CBF filter lacks control over angular velocity (follows clipping method), and only applies it over linear velocity (making the cbf's output 1D), its because making the angular velocity count means modifying the certified BF, making it, technically, no longer certified. As test case, it will batch test multiple random (but unique) states, and will output a text file containing filtered values, and each test case labelled safe/unsafe.

In future, a simulation, or graphical representation of certain test cases will be added for visualization, and to somewhat confirm whether they are actually safe.
