The simpleBc.py was made to create a simple implementation of a simple barrier function over a simple obstacle avoidance approach. The cbfOverDwa was later created as a refined version. It takes a barrier function that corresponds to a similar structure given as output by PRoTECT. Then applies it as CBF over the DWA approach. Although, this CBF filter lacks control over angular velocity, and only applies it over velocity and state. It also lacks differentiation capability for now. Needs further modification.

I have also added code that produces BF using PRoTECT (credit to Alex for that code). Will use this so that cbfOverDwa can automatically get the generated BF and use it.
